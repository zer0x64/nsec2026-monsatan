# monsatan-kiosk

## Description

We have a few kiosk-mode PC on the premise. Participants have to escape from the kiosk

## Theme

These kiosks are Monsatan's. The participants are looking for proof of foul play on their end before attacking them.

## Solutions

### Flag 1

Use the CTRL-S shortcut to open a file save dialog. Right-click->"Open in file explorer" on a directory to open a file explorer. Either just navigate to /home/kiosk/Desktop to find the file with the flag into it, or navigate to /bin/, execute the bash binary and use a `find` command in the terminal to search for the flag.
